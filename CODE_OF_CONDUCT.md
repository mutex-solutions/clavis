# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/),
version 2.1.

In short: be respectful, assume good faith, no harassment. Contributors of all backgrounds
and experience levels are welcome.

## Enforcement

Report unacceptable behavior to the maintainer (`dinhlongviolin1` on GitHub). Complaints
are reviewed promptly and fairly. Full text:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/
